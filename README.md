# Gylsere Januzi Krieg – Online Marketing Office (Astro)

High-end, performance-orientierte Website mit Astro. Branch `preview` wird via Vercel automatisch als Preview deployed. Änderungen zuerst hier prüfen, dann auf ausdrücklichen Wunsch live schalten.

## Entwicklung
- npm i
- npm run dev

## Build
- npm run build && npm run preview

## Stack
- Astro (static output)
- GSAP (ScrollTrigger) – dezente Reveals, Parallax, Counter
- Swiper – Logo-Slider
- Canvas Particles – performanter Hero-Hintergrund (pausiert off-viewport, respektiert prefers-reduced-motion)

## Kontaktformular
Sendet an n8n-Webhook (JSON): https://timokrieg.app.n8n.cloud/webhook/contact-form
Felder: name, email, phone, site, message

## SEO
- Meta, Open Graph, Twitter Cards
- JSON-LD: Organization + ProfessionalService
- robots.txt, sitemap.xml
